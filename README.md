# Telegram бот-магазин

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, вставьте токен и свой Telegram ID.
   Свой ID можно узнать, запустив бота без OWNER_IDS и написав ему `/myid`.
3. `python bot.py`

## Возможности
- `/start` — список позиций, внутри позиции — товары.
- Карточка товара: название, цена, остаток, описание, продавец + кнопка «Связаться» (по умолчанию @Cathoks).
- Админ панель (кнопка видна админам и владельцу): создать/переименовать/удалить позицию,
  добавить товар, изменить название, цену, количество, описание, продавца, удалить товар.
- Владелец может добавлять и убирать админов (по Telegram ID).
- Если количество 0 — у товара отметка ❌ «нет в наличии».
